# Machine Learning Projects

Neural network architectures developed for financial market prediction.

## Projects

| Project                         | Architecture                           | Application              |
|---------------------------------|----------------------------------------|--------------------------|
| **Chimera 2D State Space Model** | Bidirectional LSTM + Multi-head Attention | Forex reversal prediction (3-class) |
| **Sentinel Forex Transformer**   | Transformer Encoder (3 layers, 8 heads)  | XAUUSD direction prediction (binary) |

## Key Technologies

- **Framework:** PyTorch
- **Deployment:** Flask REST API, ONNX export
- **Integration:** MT5 via HTTP requests
